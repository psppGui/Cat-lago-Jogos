# Catálogo de Jogos

Aplicação web desenvolvida em Java com Spring Boot para cadastro e organização de jogos.


## Tecnologias

- Java  -25.0.4.1
- Spring Boot -4.1.1
- Thymeleaf
- Spring Data JPA
- MySQL - 8.0.46
- Maven
- HTML
- CSS

## Funcionalidades
- Cadastro de jogos
- Listagem de jogos
- Pesquisa por título
- Exclusão de jogos
- Persistência dos dados com MySQL
